# Pattern Nodes

이미지를 올리고 노드를 이어서 패턴을 만드는 빈 노드 사이트예요. 서버도 라이브러리도 없이, 파일만 올리면 돌아가요.

## 올리는 법 (네오시티)

아래 7개를 **같은 폴더**에 올리세요. 하나라도 빠지거나 예전 버전이 섞이면 화면 맨 위에 검정 안내 띠가 떠요.

- `pattern.html` (여기로 접속: `.../pattern`)
- `pn-style.css`
- `pn-engine.js`, `pn-nodes.js`, `pn-store.js`, `pn-samples.js`, `pn-editor.js`

기존 사이트의 `index.html`, `style.css`, `app.js` 등과 이름이 겹치지 않게 모두 `pn-` 접두사를 붙였어요. 올린 뒤에는 강력 새로고침(Ctrl/Cmd+Shift+R)을 해 주세요. `README.md`는 안 올려도 돼요.

## 쓰는 법

- **노드 추가:** 위쪽 `+ 노드`, 빈 곳 우클릭, 또는 빈 곳 두 번 클릭
- **이미지 올리기:** 이미지 노드의 `올리기`, 또는 파일을 화면에 끌어다 놓기 (노드 위에 놓으면 그 노드의 이미지가 바뀌어요)
- **연결:** 오른쪽 둥근 점(출력)에서 다른 노드의 왼쪽 점(입력)으로 끌어요. 입력 점을 잡아서 허공에 놓으면 끊겨요. 선을 두 번 클릭해도 끊겨요.
- **재료/구멍 맞바꾸기:** 구멍·겹치기 노드 머리의 `⇄`
- **이동·확대:** 빈 곳 드래그(이동), 마우스 휠(확대), `전체 보기` 또는 `F`
- **선택:** 클릭, `Shift`+클릭, `Shift`+드래그(여러 개), `Delete`(삭제), `Ctrl/Cmd+D`(복제), `Ctrl/Cmd+Z`(되돌리기)
- **슬라이더:** 이름을 두 번 클릭하면 기본값으로 돌아가요
- **오른쪽 미리보기:** 클릭한 노드의 결과가 보여요. `2×2 반복 보기`로 이음새를 확인하고, `PNG 저장`으로 내보내고, `기록 저장`으로 어떤 노드를 어떤 설정으로 거쳤는지 글로 남겨요.

## 규칙

- 모든 연결선은 같은 규격이라서 어떤 출력도 어떤 입력에 꽂을 수 있어요. 한 화소는 「얼마나 차 있는가(0~1)」와 「무슨 색인가」예요.
- 종이는 연결선 안에 없어요. **출력**에서 종이 색을 한 번만 깔아요(또는 「배경 투명」).
- 색은 두 군데서 생겨요: **겹치기**의 잉크 색, 그리고 **이미지(모듈)**가 가진 원래 색. 구멍(재료 쪽)·변환·반복·팽창/수축은 색을 그대로 이어 가고, 굴곡은 모양만 읽어서 다시 한 색이 돼요.
- 노이즈·격자·굴곡·흐림은 가장자리가 이어지게 계산돼서, 반복해도 이음새가 거의 안 생겨요. 이미지는 `맞춤`을 `거울 이음`으로 두면 이어져요.

## 모듈로 패턴 만들기 (Whirligig 같은 겹침)

1. 배경을 지운 **투명 PNG** 모듈을 이미지 노드에 올려요 → 자동으로 `쓰임: 모듈`(원래 색·투명 유지, 여백 자동 자르기)이 돼요. 픽셀 모듈은 `픽셀 유지`를 켜요.
2. 모듈마다 **변환** 노드로 크기·회전·위치를 정해요. 중심은 화면 가운데라서 같은 중심에 겹쳐 쌓여요.
3. 윤곽선 층이 필요하면 같은 모듈을 **팽창·수축**(`테두리만`)에 한 번 더 통과시켜요.
4. **겹치기**에서 `합성: 덮기`로 위 층이 아래 층을 가리게 쌓아요(최대 6층). 층마다 `잉크`(한 색으로 칠함)/`모듈`(원래 색) 중 고르고, 모듈을 가운데 맞춰 쌓으려면 `어긋남`을 0으로.
5. **반복**으로 깔고, **출력**에서 종이 색을 정하거나 `배경 투명`을 켜서 PNG로 저장해요.

## 저장

- 작업은 이 브라우저에 자동 저장돼요(올린 이미지 포함). 다른 기기나 브라우저로 옮기려면 `저장 (.json)`으로 내려받고 `불러오기`로 열어요.
- 이미지는 긴 변 1600px로 줄여서 보관해요. 투명 PNG는 원본 PNG를 그대로(크면 같은 크기로 줄여 PNG로), 불투명 사진은 JPEG로 보관해요. 같은 이미지는 한 번만 저장해요.
- `저장 (.json)` 옆의 `이미지 포함`을 끄면 JSON이 아주 작아져요(노드 연결과 설정만). 대신 불러온 뒤 이미지를 다시 올려야 해요. 이미지가 합쳐서 약 6MB를 넘으면 알려 드려요.
- 옛 저장본·샘플도 그대로 열려요(겹치기의 종이 색은 출력으로 옮겨져요).

## 성능

- 슬라이더를 끄는 동안은 256px로, 놓으면 512px로 계산해요. 바뀐 노드와 그 뒤 노드만 다시 계산해요.
- PNG는 1024 / 2048 / 4096px. 색이 있는 결과의 4096은 7~10초쯤 걸리고 메모리를 많이 써요(멈추면 2048로). 투명 PNG도 같아요.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `pn-engine.js` | 계산 순서, 캐시, 내보내기용 계산 |
| `pn-nodes.js` | 노드 정의. `reg('이름', {...})` 하나를 추가하면 메뉴와 화면에 자동으로 나타나요 |
| `pn-editor.js` | 노드 편집 화면 |
| `pn-store.js` | 자동 저장, JSON |
| `pn-samples.js` | 샘플 3개 |
